# Moon Orbit 

This project is a simple Moon Orbit animation built with **HTML and CSS** as part of the freeCodeCamp Responsive Web Design course.

##  Project Overview

The project shows the Moon orbiting around the Earth using CSS positioning, transforms, and animations.

##  Technologies Used

* HTML5
* CSS3
* CSS Flexbox
* CSS Positioning
* CSS Animations

##  Features

* Earth positioned at the center
* Moon positioned around the Earth
* Circular orbit
* Continuous Moon animation
* Simple CSS design

##  What I Learned

* How to center elements using Flexbox
* How to use `position: absolute` and `position: relative`
* How to use `transform: translate()`
* How to create animations with `@keyframes`
* How to use CSS rotation for an orbit animation
